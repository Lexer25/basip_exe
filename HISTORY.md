basip_ctrl_panel - History

Версия: 2.0.3.4
1. Исправлена ошибка сборки: в классе DB метод CreateConnection был объявлен дважды (CS0111).
2. Убрана неразрешимая ссылка на basip_ctrl.dll: библиотека в коде не использовалась,
   файла .\libs\basip_ctrl.dll в репозитории нет (предупреждение MSB3245).
3. Починена проверка связи с панелью: метод FixDeviceErr сравнивал числовой ID_CARD
   со строкой 'OK' вместо LOAD_RESULT, из-за чего при недоступности панели
   перезаписывался статус всех карт.
4. Исправлен разбор времени: timestart читался из options.timeout, поэтому время
   первой итерации игнорировалось. Добавлен безопасный разбор timeout и timestart.
5. Убран повторный вызов Auth(): на каждую панель за итерацию уходил лишний HTTP-запрос.
6. Контроль версии API: панели с API 3.0 больше не считаются поддерживаемыми
   (было major == 3 && middle > 0).
7. Номер карты, не являющийся числом, больше не роняет обработку панели
   (Convert.ToInt64 заменён на TryParse).
8. Ответ панели с HTTP-ошибкой и непустым телом больше не считается признаком связи;
   JsonDocument.Parse больше не падает на не-JSON теле.
9. SQL-запросы GetCardForLoad, DeleteCardInDev, UpdateCardInDevIncrement переведены
   на параметры вместо подстановки значений в текст запроса.
10. Строка подключения к БД убрана из appsettings.json (пароль не хранится в git);
    добавлен образец appsettings.Development.json.example.
11. Environment.Exit(1) заменён на штатную остановку хоста через IHostApplicationLifetime.
12. Удалён неиспользуемый код: DeviceInfo.cs, _EventInsert, GetAllEventTypes, EventType,
    InitializeEventTypeMapping, ConvertNameToKey, неиспользуемые using и поле hashPassword.
13. Версии приведены к единому значению 2.0.3.4: приложение, установщик, README.
14. Исправлен ярлык "Просмотр логов" в установщике: указывал на {app}\logs\app.log
    вместо фактического C:\ProgramData\Basip\ArtonitBasIpTools.log.
15. Сборка проходит без ошибок и предупреждений.
